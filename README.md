# مدرسة السياقة التونسية — مشروع اللعبة

## البنية
```
src/
  index.template.html     هيكل الصفحة (يُملأ بالبناء)
  css/style.css           الأنماط
  assets/signs.js         صور العلامات (base64) — 195 صورة
  js/01…14-*.js           وحدات الكود بالترتيب (نطاق عام واحد، تُضم بالترتيب)
build.py                  يجمع كل شيء في dist/index.html (ملف واحد مستقل)
dist/                     ناتج البناء + vercel.json (جاهز للنشر)
tests/smoke.js            يشغّل كل المراحل بمحاكاة المتصفح ويكشف الأخطاء
tests/shaders-gl.js       يترجم كل الشيدرات في Chromium (يحتاج playwright)
```
ترتيب الوحدات: 01 الرسم والمصفاة · 02 الشيدرات · 03 المعالجة اللاحقة والسماء · 04 النسيجات وبُناة الهندسة · 05 إطار الرسم · 06 العالم · 07 نواة اللعبة · 08 اليد والمفاتيح · 09 الصوت · 10 الوضعيات والامتحانات · 11 بيانات العلامات والأسئلة · 12 المراحل والقائمة والمناورات · 13 الفيزياء · 14 اللوحة والحلقة الرئيسية.

## البناء والفحص
```
python3 build.py                 # ينتج dist/index.html
node tests/smoke.js              # يجب ألا يطبع أي ERROR
npm i playwright && node tests/shaders-gl.js
```
## النشر على Vercel
اسحب مجلد `dist/` إلى vercel.com/new، أو: `cd dist && npx vercel deploy --prod`.

## الأداء (مفاتيح داخل اللعبة)
* **P**: يعرض الإطارات/ثانية وزمن الإطار وعدد أوامر الرسم والمثلثات والدقة الحالية.
* زر 🎨 في القائمة: الجودة (منخفضة/متوسطة/عالية/قصوى). زر ☀️: السطوع.
* قواعد الصيانة: لا تُنشئ مادة أو نسيجًا في كل إطار؛ استعمل `Mt()` و`SMc()` للمواد المشتركة؛ حرّر موارد المرحلة في `sgClear()`؛ ما لا يتغير يُرسم في `buildStatic()` لا في `dash()`.
